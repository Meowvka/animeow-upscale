# Пайплайн качества animeow

Два мира с разными ограничениями — и два разных инструмента.

```
                      ┌─────────────────── СЕРВЕР (один раз) ───────────────────┐
 постеры, баннеры,    │  _orig/…  ──►  Real-ESRGAN AnimeVideo-v3 (×4, ONNX, CPU) │──► covers/… (готовые файлы)
 кадры, пре-кадры     │               └─ ×2 / ×1 уменьшением (lanczos)           │    устройству — 0 работы
                      └──────────────────────────────────────────────────────────┘

                      ┌─────────────── БРАУЗЕР (каждый кадр видео) ──────────────┐
 серия (HLS)  ──►     │  MeowRestore (наша сеть, 2–45 КБ)  ──►  Anime4K Upscale  │──► <canvas> поверх <video>
                      │   «сначала модель»                      «потом шейдеры»  │
                      └──────────────────────────────────────────────────────────┘
```

## Почему так

**Картинки — только на сервере.** У сайта все картинки свои (папка медиа, `_orig/` — исходники).
Значит, можно позволить себе сеть, которая в браузере неподъёмна: Real-ESRGAN AnimeVideo-v3 —
~0.6 млн параметров (в 40–600 раз больше Anime4K/MeowRestore), обучена на аниме, убирает блоки
сжатия и мыло заметно лучше. Посетитель скачивает обычный WebP — ни весов, ни вычислений.
Пре-кадры серий (сейчас `enhanceStills` в браузере) — тоже сюда, при первом показе.

**Видео — в браузере, но маленькой сетью.** Для видео важен не вес файла, а вычисления на кадр:
24 кадра в секунду × сотни тысяч пикселей. Даже 65 КБ весов — это ~16.6 тыс. умножений на пиксель,
~30 GFLOP на кадр 720p. Поэтому сеть — в формате Anime4K (свёртки 3×3 по 4–12 каналов, CReLU),
исполняется шейдерами, без onnxruntime (тот весит 10–25 МБ и не успевает за видео).

**Сначала модель, потом шейдеры.** MeowRestore работает в исходном разрешении (дёшево: пикселей
в 4 раза меньше, чем после ×2) и чистит то, что испортил стриминг. Anime4K Upscale дальше
увеличивает уже чистый кадр — не размножая артефакты сжатия.

Главное преимущество своей сети перед Anime4K Restore — её можно **обучить на ваших же потоках**:
на тех битрейтах и тех порчах (480→720 апскейл, пересжатие), что реально приходят от источников.

## Уровни для видео

| Устройство | WebGPU | WebGL2 |
|---|---|---|
| Десктоп | ClampHighlights → **MeowRestore L** → CNNx2VL → CNNx2M (`MeowPreset`) | **MeowRestore M** → Anime4K Upscale S |
| Ноутбук / сильный телефон | **MeowRestore M** + CNNx2M | **MeowRestore S** → Anime4K Upscale S |
| Слабый телефон | — | **MeowRestore S** → Anime4K Upscale S, при пропусках — резкость (CAS), как сейчас |

`web/src/tiers.ts → pickSize()` выбирает потолок; дальше работает уже существующий в плеере
механизм «пропущена треть кадров → шаг вниз» (`stepDown()`: L → M → S → резкость).

## Сколько это стоит

Размеры моделей (параметров ≈ умножений на пиксель):

| Модель | Параметров | Веса (.meow.json) | GLSL-текст | Для кого |
|---|---|---|---|---|
| MeowRestore S | 915 | 2.7 КБ | 13 КБ | телефоны (дешевле Anime4K Restore S) |
| MeowRestore M | 5 299 | 14 КБ | 69 КБ | ноутбуки, сильные телефоны |
| MeowRestore L | 16 611 | 45 КБ | 211 КБ | десктоп с WebGPU («65 КБ»-класс в fp32) |
| для сравнения: `anime4k-webgpu` (весь пакет) | — | 3.4 МБ JS | — | уже грузится на десктопе |

Сайту достаточно `.meow.json`: шейдеры (GLSL и WGSL) генерируются в браузере за миллисекунды.

Относительная скорость на кадре 1280×720 (`web/test/browser.mjs`, программный рендер SwiftShader —
абсолютные миллисекунды не показательны, соотношения — да):

| Проход (WebGPU) | Время |
|---|---|
| MeowRestore S | 0.08× от CNNVL |
| MeowRestore M | 0.32× |
| MeowRestore L | 0.75× |
| Anime4K CNNM (restore M) | 0.27× |
| Anime4K CNNVL (restore VL, стоит в ModeA сейчас) | 1× |

То есть `MeowPreset` с L на десктопе **дешевле** текущего ModeA, а S по числу параметров даже легче Anime4K Restore S (915 против ~1160).

## Сервер

`server/` — `createEnhancer().enhanceFile(src, dst, { scale })`: Real-ESRGAN через onnxruntime-node, тайлами,
без швов. На этой машине: постер 460×690 → 920×1380 ≈ 4.4 с на одно ядро (1.5 с на четыре),
кадр 1280×720 (восстановление) ≈ 12 с на одно ядро (4.3 с на четыре).
Для сравнения: Anime4K L на CPU у вас — ~3 с на постер. Дороже на треть, качество — другого класса;
считается один раз и в фоне (`media-enhance` уже умеет fork по ядрам и `_orig/` как отметку «сделано»).

## Качество (пробный прогон)

На синтетических кадрах с порчей как у стримингов (подробности и оговорки — `models/meow/proof/README.md`):

| | S | M | L |
|---|---|---|---|
| MeowRestore | +1.25 дБ | +2.19 дБ | +2.90 дБ |
| Anime4K Restore | +1.21 дБ | +1.55 дБ | +1.54 дБ |

Рантайм для браузера (`web/`) — 17 КБ (6 КБ gzip), без зависимостей.
