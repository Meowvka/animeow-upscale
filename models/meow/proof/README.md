# Пробные веса (синтетика) — не для продакшена

Эти веса — проверка, что весь конвейер работает от начала до конца:
`make_synthetic.py → make_pairs.py (ffmpeg, x264) → train.py → export.py → браузер (WebGL2/WebGPU)`.
Учились **на синтетических «мультяшных» кадрах** на CPU (4 ядра, 4000 шагов, 4–15 минут на размер).
Для сайта их нужно переобучить на настоящих аниме-кадрах — [docs/TRAINING.md](../../../docs/TRAINING.md).

## Результат на отложенных кадрах (другое синтетическое видео)

`web/test/compare.mjs`, 12 кадров, вырезка 384 px, исполнитель WebGL2 в Chromium — тот же формат хуков, что в плеере.

| Сеть | PSNR | Выигрыш к входу |
|---|---|---|
| вход (x264 CRF 25–32, апскейл 480→720, размытие) | 33.95 дБ | — |
| MeowRestore S (915 парам.) | 35.20 | **+1.25** |
| MeowRestore M (5.3 тыс.) | 36.14 | **+2.19** |
| MeowRestore L (16.6 тыс.) | 36.84 | **+2.90** |
| Anime4K Restore CNN S | 35.15 | +1.21 |
| Anime4K Restore CNN M | 35.50 | +1.55 |
| Anime4K Restore CNN L | 35.49 | +1.54 |

Честная оговорка: наши сети учились на таком же типе порчи и картинок, Anime4K — нет, так что сравнение
в нашу пользу по определению. Но именно это и есть довод: **сеть, обученная на ваших реальных потоках,
выигрывает у универсальной** — на настоящих кадрах это нужно подтвердить тем же `compare.mjs`.
